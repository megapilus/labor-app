# Labor-App – Einrichtung auf GitHub Pages

Dateien (alle 5 ins Repository): `index.html`, `manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png`

1. github.com → **+ → New repository**, Name z. B. `labor-app`, **Public**, **Create repository**.
2. Auf der leeren Seite im Kasten „Quick setup“ **uploading an existing file** anklicken, die 5 Dateien hineinziehen, **Commit changes**.
3. **Settings → Pages**: *Deploy from a branch*, Branch **main**, **/ (root)**, **Save**.
4. Nach 1–2 Minuten: `https://DEIN-NAME.github.io/labor-app/` in Safari öffnen → Teilen → **Zum Home-Bildschirm**.

Update: neue `index.html` über **Add file → Upload files** hochladen, 1–2 Minuten warten, in der App unter **Substanzen → ↻ App neu laden**.

Eigene Substanzen, Favoriten und letzte Eingaben werden nur auf dem Gerät gespeichert.
